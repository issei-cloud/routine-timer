# ルーティンタイマー

自宅でのトレーニングとストレッチを **習慣化する** ためのルーティンタイマーアプリです。
「続けられること」を最優先に、できなかった日にユーザーを責めない設計を貫いています。

単一の HTML で完結する PWA（ホーム画面に追加して使えるWebアプリ）です。

## 特長

- **複数ルーティン** … 朝・夜など用途別に登録し、ホームからワンタップで開始
- **時間 / 回数の混在** … ストレッチは時間で自動進行、筋トレは回数で手動完了
- **休憩の自動挿入** … 種目ごとに設定した秒数の休憩を自動で挟む
- **進捗バー** … 全体のどこまで進んだかが一目で分かる
- **動作確認の画像枠** … 種目ごとに複数枚を切り替え表示（画像登録は今後実装）
- **音** … 区切りのチャイム と ヒーリングBGM（各オンオフ可）
  - 合成音を4種内蔵（ぬくもり / しずく / なみ / ほしぞら）
  - お気に入りの **YouTube** 動画をBGMとして登録し、音だけ裏で再生（公式の埋め込みプレイヤーを使用。ダウンロードはしません）
- **やさしい記録** … 実行後は「しっかり / 少し」の2択のみ。開かなかった日は自動的に「休息の日」として扱い、責めない
- **カレンダー振り返り** … 日ごとの状態を穏やかな色で表示
- **オフライン動作 / ホーム画面追加** … Service Worker によりオフラインでも起動。スマホのホームに置ける

記録・設定・登録したBGMは、ブラウザのローカルに保存されます（端末内のみ。外部送信はありません）。

## 使い方

公開URL（GitHub Pages）をスマホのブラウザで開き、
- iOS（Safari）：共有メニュー →「ホーム画面に追加」
- Android（Chrome）：メニュー →「アプリをインストール」

で、ホーム画面にアイコンとして追加できます。

## ローカルで動かす

`file://` だと Service Worker が動かないため、簡易サーバー経由で開きます。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 構成

```
index.html              アプリ本体（UI・ロジック・合成音）
manifest.webmanifest    PWA設定
sw.js                   Service Worker（オフライン対応）
icons/                  アイコン一式
docs/requirements.md    要件定義書
```

## 技術メモ

- 依存ライブラリなしのバニラ構成（単一HTML）
- BGMは Web Audio API による合成音と、YouTube IFrame Player API を同一の選択UIで統一的に扱う設計
- 「責めない」という設計思想を、データ構造（休息の日を「記録がない状態」で表現し、保存しない）にまで反映
